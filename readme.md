### Contributing

If you find any bugs or have an idea how I can make it run more smoothly follow one of these two steps:

### 1. Reporting Issues

Open an issue in the [source-repo](https://github.com/<your_username>/source-repo) repository on GitHub. Please add steps to reproduce the issue and relevant error messages. Thank youu.

### 2. Contributing Code

1.  **Fork the `source-repo` repository:** Click the "Fork" button at the top right of the [source-repo](https://github.com/<your_username>/source-repo) repository. This will create a copy of the repository in your own GitHub account.

2.  **Clone your fork:**

    ```bash
    git clone https://github.com/<your_github_username>/source-repo.git
    cd source-repo
    ```

3.  **Create a new branch:** Give your branch a name related to the issue or feature you're working on.

    ```bash
    git checkout -b fix/safari-performance
    ```

4.  **Make your changes:** Edit the files in your local repository to fix the bug or whatever.

5.  **Test your changes:** If the changes affect the visual appearance or involve JavaScript, you'll need to build the project locally to test them. See the "Building the Project for Testing" section below.

6.  **Commit your changes:** Use descriptive commit messages.

    ```bash
    git add .
    git commit -m "Descriptive commit"
    ```

7.  **Push your changes to your fork:**

    ```bash
    git push origin fix/safari-performance
    ```

8.  **Create a pull request:** Go to the [source-repo](https://github.com/<your_username>/source-repo) repository on GitHub and click the "Create pull request" button. Make sure your pull request is based on the `main` branch and that it includes a clear and concise description of the changes you've made.

### Note

- The `dist` folder (containing the built website) is maintained in a separate repository [dist-repo](https://github.com/<your_username>/dist-repo).
